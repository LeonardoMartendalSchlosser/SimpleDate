# SimpleDate

SimpleDate é uma biblioteca Python simples, intuitiva e focada exclusivamente em **manipulação de datas**.  
Ela permite converter strings em datas, formatar datas em diferentes padrões e calcular a diferença de dias entre duas datas de maneira rápida e prática.

---

## Funcionalidades Principais

- `today()` – Retorna a data atual.
- `parse_date()` – Converte string em `date`.
- `format_date()` – Formata datas com qualquer padrão.
- `days_between()` – Calcula diferença de dias entre duas datas.
